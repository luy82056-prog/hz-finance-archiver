# 使用说明

## 基本流程

1. 打开 `HZ财务归档器`。
2. 点击“选择归档文件夹”，指定本次输出目录。
3. 拖入 PDF、图片、Word 或整个文件夹。
4. 等待处理完成，在表格里检查识别结果。
5. 如有错误，双击对应行人工校正。
6. 点击“导出到台账”，按当前字段重新写入 Excel/Word。

## 输出结果

目标文件夹中通常会出现：

- `财务台账.xlsx`：PDF/图片识别后的 Excel 台账。
- `Word汇总归档.docx`：拖入 Word 后生成的原文汇总文档。
- `项目名称 金额.pdf`：移动并改名后的 PDF 原文件。
- `项目名称 金额.png/jpg/...`：移动并改名后的图片原文件。

软件不会再额外复制一份原文件，也不会在目标目录创建 SQLite 数据库。

## 导出字段

点击“编辑导出字段”后，勾选需要的字段即可。可选字段都是软件已经适配的字段，例如：

- 文件名
- 项目名称
- 金额
- 文档类型
- 供应商/对方户名
- 日期
- 发票号/流水号
- 币种
- 归档路径
- 处理状态
- 备注
- 识别置信度
- 税额
- 税率

## Word 汇总

Word 文件不会强行识别图片里的文字，而是按原文汇总：

- 保留段落文字
- 保留简单表格
- 保留图片

适合把多个分散的报销说明、截图、表格集中到一个 `Word汇总归档.docx`。

## OCR 说明

数字 PDF 优先读取文字层。扫描件或图片 OCR 需要安装 Tesseract 和中文语言包。未安装 OCR 时，软件仍可处理文字层 PDF 和 Word。

## 常见问题

- 金额不对：软件优先取发票的 `价税合计（小写）`，如遇特殊票面可人工校正后重新导出。
- 项目名不对：双击行修改“项目名称”，再点击“导出到台账”。
- Word 显示未知：新版 Word 按原文汇总，不再依赖字段识别；请确认使用的是新版包。
- 归档文件名重复：软件会自动加 `_2`、`_3`，不会覆盖旧文件。
